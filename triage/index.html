private triage agent

An open source privacy preserving email triage agent. A local model (gemma3:27b) handles every email; and when harder reasoning is needed, sensitive content is anonymized before being sent to Claude, then re-hydrated locally.

what it does

The local model triages every email: category, summary, action items, and starts a reply draft. When the local model is uncertain or the data looks sensitive (legal, financial, etc) it gets anonymized before being sent to Claude for stronger processing, then re-hydrated locally, so Claude only ever sees placeholder text. Approved drafts are saved in your inbox's Drafts folder.

the anonymization stack

Three layers run in sequence ensuring every entity maps to a consistent, proper-noun-shaped placeholder.

  • 1
    Deterministic regex Fixed-shape PII: email addresses, phone numbers, dollar amounts, dates. Fast and exact, but won't catch anything without a predictable pattern.
  • 2
    Transformer NER A spaCy RoBERTa pipeline (en_core_web_trf) tags the open-ended proper nouns: people, organizations, locations, facilities. This turns Sarah into Alex_P1 and Northwind into Acme_O1.
  • 3
    Neural coreference fastcoref (biu-nlp/f-coref) links every pronoun back to its entity, so “Sarah,” “she,” and “her” come back as one chain (Alex_P1, They_P1, Their_P1). A bare “she” three sentences later resolves to the right person. Pronouns aren't named entities, so only the coref chain can catch them.

Because coreference models are imperfect, a held-out eval harness measures the residual PII leak rate of each layer.

security

local api

Any web page can probe local ports, so each run gets a fresh token the Vite proxy attaches to every request, and the server checks that the the Host and Origin headers match the expected values. The page itself never holds the token or your IMAP password.

imap

Read-only: folders open with readonly=True and bodies fetch via BODY.PEEK[], so nothing gets marked as read, deleted, or sent. The one write is the APPEND of an approved reply into your Drafts folder.

supply chain

Everything is pinned. Dependencies come from a lockfile with specific versions. NER wheel is pinned to its SHA-256. Package-age check fails anything published less than 14 days ago.

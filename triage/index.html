private triage agent

An open source privacy-preserving email triage agent. A local model handles your whole inbox on your machine; and when harder reasoning is needed, sensitive content is anonymized before it is sent to Claude, then re-hydrated locally. Nothing is ever sent without your approval.

local-first gemma3:27b via Ollama regex + NER + coref anonymization Claude escalation human review of every draft

what it does

The local model triages every email: category, summary, action items, and a reply draft. When it is uncertain or the content looks sensitive (legal language, negotiations, dollar figures), the email is anonymized, sent to Claude for a stronger draft, then re-hydrated locally. The raw text of your mail never leaves your machine; Claude only ever sees placeholder-substituted text.

Every draft lands in a review queue in a React web app backed by a local API over the Python pipeline. You approve, edit, or reject each one; approved replies become IMAP drafts in your own mail client or click-to-send .eml files. The pipeline itself never sends anything.

the anonymization stack

Three sequential layers run on progressively cleaner text, each covering a failure mode the others structurally miss. Overlapping spans resolve longest-match-first, replacements apply right-to-left so offsets stay valid, and every entity maps to a stable, proper-noun-shaped placeholder that Claude reads as in-distribution text rather than an opaque redaction.

  • 1
    Deterministic regex Fixed-shape PII: email addresses, phone numbers, dollar amounts, dates. Fast and exact, but blind to anything without a predictable pattern.
  • 2
    Transformer NER A spaCy RoBERTa pipeline (en_core_web_trf) tags the open-ended proper nouns: people, organizations, locations, facilities. This is what turns Sarah into Alex_P1 and Northwind into Acme_O1.
  • 3
    Neural coreference fastcoref (biu-nlp/f-coref) links every pronoun back to its entity, so “Sarah,” “she,” and “her” come back as one chain (Alex_P1, They_P1, Their_P1). A bare “she” three sentences later resolves to the right person instead of leaking. Pronouns aren't named entities, so only the coref chain can catch them.

Because coreference models are imperfect, a held-out eval harness measures the residual PII leak rate of each layer.

review everything before it sends

Select an email from the ranked queue to see the original message, summary, action items, escalation decision, and an editable draft. Choose Approve, Approve edit, or Reject; approved drafts land in your IMAP Drafts folder or as a pre-filled .eml, one click from sending in your own mail client.

security

local api

Localhost is not a security boundary: any web page can probe local ports. Every API request needs a per-run token that the Vite proxy injects, so browser JavaScript never sees it, plus strict Host and Origin checks. The browser never receives the anonymization mapping or the IMAP password.

imap

Reading is read-only, enforced twice: folders open with readonly=True and bodies fetch via BODY.PEEK[], so nothing is ever marked read, deleted, or sent. The one write is the explicit APPEND of an approved reply into your Drafts folder.

supply chain

Dependencies install from a lockfile with exact pins; the NER model wheel is pinned to its SHA-256. A package-age check rejects anything published less than 14 days ago and fails closed. The coref model is locked to an immutable commit with per-file hashes, copied into an isolated runtime directory that is hash-checked before every load; mail processing never downloads models.
